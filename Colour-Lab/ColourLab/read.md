# Colour Lab - quick start

1. Open this folder in VS Code and open a terminal.
2. Type `make` (or `mingw32-make`) and press Enter. The game builds and starts.
3. Keys: R B Y G M C = colours, Backspace = remove, Enter = check, Space = next / try again, Esc = quit.

More details are in `ReadMe.md` and `instructions.txt`.
